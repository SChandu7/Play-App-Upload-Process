Playstore Upload Process

Follow the exact steps below to configure and upload your app.

1. create a Flutter project with the Command as "Flutter create demo"

1.1 edit the lib file code with your own app flow code a

1.2 check there's no errors by running "flutter build apk" in the root folder of the project as c://flutter_projects/demo/ then run command and get an apk files in project root then there's no error

1.3 --> Flutter project programming Completed

2.Config Sign in key

2.1 Run this command in project root and answer questions after you'll get a upload-keystore.jks file
==>

keytool -genkey -v -keystore upload-keystore.jks -keyalg RSA -keysize 2048 -validity 10000 -alias upload

2.2 copy that file as name "uplaod-keystore.jks" and place in demo/android/app/

2.3 create a new file named wiht "key.properties" and save the file in demo/andorid/

2.3.1 in key.properties files add those text as you entered in cerating keystore in "2.1"

storePassword=YOUR_KEYSTORE_PASSWORD
keyPassword=YOUR_KEY_PASSWORD
keyAlias=upload
storeFile=upload-keystore.jks

2.4 now configure build.gradle file as location demo/android/app/build.gradle
as paste this after plugins like a different block as

// 🔐 Load keystore properties
val keystoreProperties = Properties()
val keystorePropertiesFile = rootProject.file("key.properties")
if (keystorePropertiesFile.exists()) {
    keystoreProperties.load(FileInputStream(keystorePropertiesFile))
}

and in andoird block replace the block buildtypes{} as

 buildTypes {
         getByName("release") {
            signingConfig = signingConfigs.getByName("release") // ✅ RELEASE KEY
            isDebuggable = false
            isMinifyEnabled = false
            isShrinkResources = false
        }
    }

and add this block above buildtypes as

signingConfigs {
        create("release") {
            keyAlias = keystoreProperties["keyAlias"] as String
            keyPassword = keystoreProperties["keyPassword"] as String
            storeFile = file(keystoreProperties["storeFile"] as String)
            storePassword = keystoreProperties["storePassword"] as String
        }
    }

and add imports in that same file as

import java.util.Properties
import java.io.FileInputStream

2.5 now the sign in key for playstore done

2.6 now run flutter build aapbundle and get the file of aabbundle file in project demo/build/***/**/**/app-release.aab
